# Introduction to GPU Computing on HPC Systems: From CPUs to Accelerators

Training event of [EuroCC Cyprus](https://eurocc.cyi.ac.cy/), November 13th 2026. The agenda and other details about this event can be found [here](https://eurocc.cyi.ac.cy/introduction-to-gpu-computing-on-hpc-systems-from-cpus-to-accelerators/).

This repository contains the slides and exercises of the sessions "The Aphroditi HPC system" and "Running GPU Workloads on HPC Systems".

- **Slides:** [castorc-cyi.github.io/NCC-training-202611](https://castorc-cyi.github.io/NCC-training-202611/) (source in [`docs/`](docs/))
- **Exercises:** [`exercises/`](exercises/), also available on Aphroditi under `/onyx/data/edu30/`
